# Reading notes

One file per book or long article: `<title>.md`, or `<author>/<title>.md` when an
author has several.

- Frontmatter: `title` (the work's title), `tags`, `book_author`, `status`
  (`reading`, `finished` or `paused`) and, when finished, `finished_at`.
- Quote passages as block quotes followed by their page or location, and keep the
  owner's thoughts outside the quotes. Short quotations only; never copy whole
  chapters.
- Add to the existing file when the owner returns to a work.
- To publish, move the note to `public/reading/` with the same name and add a
  fresh lowercase UUID `id`.
