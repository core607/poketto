# Private content

Store new notes here unless the owner requests publication. Locate and update an
existing record before making a second one. Choose categories from the content's
use, and add a short guide when a category needs its own organization rules.

Keep media next to its document as a logical path or in a shared local category
when several documents use it. Use relative links. Neither an explicit article
route nor a link from a public document makes a private file publishable.
